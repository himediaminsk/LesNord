# NordWood78 — лендинг с мини-админкой

Правка текстов и картинок прямо на странице, как в Текстолите: кликнул — исправил — сохранил.
Без базы данных и без сборки. Нужен только PHP 7.4+ на хостинге.

---

## Что в пакете

| Файл / папка | Зачем |
|---|---|
| `index.php` | Точка входа: отдаёт готовую страницу |
| `page.html` | Вёрстка лендинга. Правится разработчиком, а не заказчиком |
| `cms/index.php` | Панель: вход, смена пароля, история версий, сброс |
| `cms/core.php` | Ядро: хранение, авторизация, применение правок |
| `cms/api.php` | Сохранение текстов и загрузка картинок |
| `cms/editor.js`, `cms/editor.css` | Панель правки поверх сайта |
| `cms/data/content.json` | Все правки. Единственный файл, который меняется при работе |
| `cms/data/backups/` | Автокопии: последние 20 сохранений |
| `upload/` | Загруженные картинки |

---

## Установка за пять минут

1. Скопируйте содержимое папки на хостинг — в корень домена или в подпапку, например `/lp/`.
2. Дайте права на запись папкам `cms/data` и `upload` (обычно 775).
3. Откройте `ваш-сайт/cms/` и войдите с паролем **`nordwood78`**.
4. Сразу смените пароль в блоке «Пароль» — до этого панель видна всем, кто знает адрес.
5. Нажмите «Открыть сайт» и правьте.

Если сайт лежит в подпапке, открывайте адрес со слешем на конце: `сайт.ru/lp/`, а не `сайт.ru/lp`.

## Как правится контент

Панель появляется внизу справа **только у вошедшего администратора**. Обычный посетитель
не получает ни одного лишнего запроса: скрипт проверяет метку-cookie и молча выходит.

- **Текст.** «Включить правку» → блоки обводятся зелёным → кликните и печатайте.
  Вставка из Word приходит чистым текстом, чужое оформление не тащится.
- **Картинки.** Обведены красным. Клик → выбор файла → картинка сразу меняется на странице.
  Принимаются JPG, PNG, WEBP, GIF до 6 МБ.
- **Фон первого экрана.** Тоже кликабелен — большая фотография склада меняется одним файлом.
- **Сохранение.** Кнопка «Сохранить» или Ctrl+S. Пока не сохранили, счётчик показывает,
  сколько блоков изменено, а уход со страницы вызовет предупреждение.

Всего доступно для правки **308 текстовых блоков и 38 изображений** — это весь видимый
контент лендинга: заголовки, описания, цены, товары, адреса, телефоны, вопросы и ответы.

## Почему это безопасно

Исходная вёрстка `page.html` **никогда не перезаписывается**. Правки лежат отдельно и
накладываются на вёрстку при отдаче страницы. Отсюда три следствия:

- Сломать дизайн правкой текста невозможно.
- Любое сохранение можно откатить в разделе «История версий».
- Кнопка «Вернуть исходную вёрстку» возвращает всё к состоянию сдачи проекта.

Дополнительно: пароль хранится хэшем, после 8 неверных попыток вход блокируется на 15 минут,
запросы защищены CSRF-ключом, в загруженных файлах проверяется реальный тип картинки,
а выполнение скриптов в `/upload` запрещено на уровне `.htaccess`.

## Скорость

Готовая страница кэшируется в `cms/data/cache.html` и пересобирается только после сохранения.
То есть посетитель получает статику: разбор HTML происходит один раз на правку, а не на запрос.

---

## Если хостинг на nginx

Правила из `.htaccess` нужно перенести в конфиг:

```nginx
index index.php;

location = /page.html { deny all; }
location ^~ /cms/data/ { deny all; }
location ^~ /upload/ {
    location ~ \.php$ { deny all; }
}
```

## Что править разработчику

- **Форма заявки** пока показывает сообщение об успехе без отправки. Обработчик подключается
  в конце `page.html` — в комментарии указано место.
- **Цены и позиции** в калькуляторе заданы массивом `PRODUCTS` там же: сечение, длина,
  полезная ширина и цена за штуку.
- **Фирменные цвета** — переменные в начале стилей, зелёный `#188b30` меняется в одной строке.

---

## Пароль забыт

Удалите файл `cms/data/auth.json` — он пересоздастся с паролем `nordwood78`.
Контент при этом не пострадает.
